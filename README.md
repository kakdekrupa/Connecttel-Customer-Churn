# 📡 ConnectTel Customer Churn Prediction

An end-to-end machine learning pipeline that predicts which ConnectTel customers are at risk of churning — from raw data to a deployed, interactive prediction app.

---

## 🎯 Project Overview

ConnectTel loses recurring revenue every time a customer churns. This project builds a classification model that flags high-risk customers **before** they leave, so the retention team can step in with targeted offers rather than reacting after the fact.

**Success criteria:** high Recall (catch as many actual churners as possible) balanced against reasonable Precision (don't flood the retention team with false alarms).

## 📓 Running the Analysis Notebook

```bash
jupyter notebook notebooks/churn_analysis.ipynb
```

Run all cells top to bottom. The notebook is structured as a single continuous report:

1. **Problem Statement** — business goal and success metrics
2. **Data Loading & Cleaning** — handles the Excel-specific column naming (spaces stripped, `Churn Label` → `Churn`, etc.) and the 11 blank `TotalCharges` rows (new customers, tenure = 0)
3. **Exploratory Data Analysis** — 5+ annotated figures, including:
   - Contract type vs churn (Month-to-month: 42.7% vs One-year: 11.3% vs Two-year: 2.8%)
   - Internet Service vs churn (Fiber Optic: 41.9% vs DSL: 19.0% vs None: 7.4%)
   - Correlation heatmap of numeric features
4. **Feature Engineering** — `TenureGroup`, `AvgMonthlySpend`, `NumServices`, `HighRiskFlag`
5. **Modeling** — Logistic Regression, Random Forest, and XGBoost, each with 5-fold cross-validation
6. **Hyperparameter Tuning** — GridSearchCV over XGBoost's `n_estimators`, `max_depth`, `learning_rate`
7. **Evaluation** — confusion matrix heatmap, ROC curve comparison across all three models, Precision/Recall/F1
8. **Interpretability** — SHAP summary plot showing global feature importance
9. **Business Insight Report** — data-backed recommendations for the retention team
10. **Model Export** — saves `churn_model.pkl`, `scaler.pkl`, and `model_columns.pkl` to `models/`

> Run the full notebook at least once before launching the app — the app loads the `.pkl` files this notebook produces.

## 🚀 Running the Prediction App

```bash
streamlit run app/streamlit_app.py
```

Opens at https://connecttel-customer-churn-l2ebpyugosa9fm6sauoe46.streamlit.app/ 
The app:
- Takes a customer's profile as input (tenure, charges, contract, internet service, tech support)
- Runs an animated pipeline (**Input Received → Preprocessing → Model Scoring → Result Ready**) that clears itself once the result is ready
- Displays a color-coded **risk gauge** (green/amber/red) with the churn probability
- Shows the **top 5 contributing factors** for that specific customer's score, using live SHAP values — red bars push risk up, blue bars pull it down
- Flags high-risk customers (probability > 50%) for retention team follow-up

## 📊 Key Findings

| Insight | Detail |
|---|---|
| Strongest churn driver | Contract type — Month-to-month churns at **42.7%**, vs 11.3% (1yr) and 2.8% (2yr) |
| Second strongest driver | Internet Service — Fiber Optic churns at **41.9%**, more than double DSL |
| High-risk segment | Fiber Optic + above-median monthly charges → **41.0%** churn vs 26.5% baseline |
| Service bundling effect | Customers with 5–6 add-on services churn at **5–12%**, vs 21–46% for 0–1 services |

Full recommendations are in the notebook's **Business Insight Report** section.

## 🐛 Known Issues & Fixes Applied

| Issue | Fix |
|---|---|
| `KeyError` on `InternetService`, etc. | Excel column names have spaces (`Internet Service`) — stripped via `df.columns.str.replace(' ', '')` right after load |
| `AttributeError: 'float' object has no attribute 'round'` | `sklearn.metrics` functions return native Python floats on newer versions — use `round(x, 3)` instead of `x.round(3)` |
| Column mismatch at deployment | Streamlit app aligns input to training columns via `reindex(columns=model_columns, fill_value=0)` |
